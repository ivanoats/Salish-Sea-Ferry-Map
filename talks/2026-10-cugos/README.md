# CUGOS lightning talk, October 2026

*One Sea, 23 Ferry Operators, Zero Maps.* A 20-slide Ignite talk (15 seconds a slide).

- `salish-sea-ferry-ignite.html`: the deck as one self-contained file, for the talk laptop or a USB stick. Open it in a browser. Press **S** for speaker notes.
- `web/`: the same deck split into cacheable files (reveal.js, CSS, WebP images). `npm run talks` stages it into `public/talks/cugos/`, and the site serves it at [/talks/cugos](https://salishseaferrymap.com/talks/cugos).

Both versions open paused. Press **A** (or the play button) to start the 15-second auto-advance, or open the URL with `?ignite` (`#ignite` for the local file) to start it straight away.
- `assets/`: Salish Sea illustration experiments built from the design elements of Coast Salish art (circle, crescent, extended crescent, trigon). They are inspired by those elements, not Coast Salish art, and are not for sale or merchandise.
